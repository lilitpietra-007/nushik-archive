# Nushik Malkhasyan Archive — Armenian / English text

206 strings across five pages. 200 exist in both languages; 6 are deliberately one-language only.

## How to use this

Every string has an ID like `CROSS-07`. Write your corrected Armenian on the `fix:` line underneath — leave it blank where the Armenian is already right. Add a comment after `note:` if the English needs changing too. Send the file back however is easiest; the IDs are what I match on, so nothing else has to stay tidy.

**Please look especially at:** the grammatical case endings, which are the likeliest thing to be wrong; whether the register sounds like a museum label rather than a translation; and the craft vocabulary — I chose Armenian terms for *doily*, *filet lace*, *picot*, *hook* and *thread count* without knowing which words are actually used in Dilijan.
